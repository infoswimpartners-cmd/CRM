## 2. 共通パーツのシンボル化（最重要KPI：LINEボタン）

STUDIOでは、同じボタンを「シンボル（Symbol）」化しておくことで、リンク先URLや文言を一括管理できます。

  1. **LINEアイコン**: SVG / 画像 (`24px × 24px`, `#06c755`)

## 4. 水モチーフ（ウェーブSVG・水滴）をSTUDIOで綺麗に表現するテクニック

1. **水面ウェーブSVGの配置方法**:
   - IllustratorやSVGコードから書き出した「波型SVG」をSTUDIOに画像としてアップロードします。
   - 横幅: `100%`, 高さ: `auto`（比率維持）に設定し、セクションの最上部または最下部にマージン `0` で配置します。
2. **水滴バブル・光彩グラデーション**:
   - STUDIOの「Box」を追加し、サイズ `200px × 200px`, 角丸 `9999px` に設定。
   - 背景色: `Aqua Blue` (`#00b4bf`), 不透明度 (Opacity): `10%`。
   - フィルターメニューから「ぼかし (Blur)」を `40px` に設定し、カードの背景に配置することで、上品な水面の反射光を再現できます。
