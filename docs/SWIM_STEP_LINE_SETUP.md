# スイムステップ LINE公式アカウント 運用・設定マニュアル

城東小学校プールで開催する「10月限定・少人数水泳教室（スイムステップ）」のLINE公式アカウント導入・運用ガイドです。

---

## 1. LIFFアプリの登録（LINE Developersコンソール）

1. [LINE Developersコンソール](https://developers.line.biz/) にログインします。
2. 対象プロバイダー内の「LINEログイン」チャネル（または新規作成）を選択します。
3. **「LIFF」タブ** を開き、「追加」ボタンをクリックします。
4. 以下の項目を設定します：
   - **LIFFアプリ名**: スイムステップ申し込み
   - **サイズ**: `Full`（または `Tall`）
   - **エンドポイントURL**: `https://{あなたのドメイン}/swim-step`
   - **Scopes**: `profile`, `openid`
   - **ボットリンク機能**: `Normal`（または `Aggressive`）
5. 作成後、発行された **LIFF ID**（例: `1234567890-abcdefgh`）を環境変数に設定します：
   ```env
   NEXT_PUBLIC_SWIM_STEP_LIFF_ID="1234567890-abcdefgh"
   ```
   ※未設定時は既存の `NEXT_PUBLIC_LIFF_ID` にフォールバックします。

---

## 3. リッチメニューの構成とアクション設定

LINE Official Account Managerの「リッチメニュー作成」から、画面下部メニューを設定します。

### 推奨レイアウト（大サイズ・4分割または6分割）

- **【メイン大型ボタン】（上部全幅または中央上）**:
  - 画像テキスト: `【10月限定】スイムステップに申し込む`
  - アクションタイプ: `リンク`
  - URL: `https://liff.line.me/{あなたのLIFF_ID}`
- **【左下ボタン】**:
  - 画像テキスト: `📅 日程・クラス案内`
  - アクションタイプ: `テキスト`
  - 送信テキスト: `日程案内`
- **【中央下ボタン】**:
  - 画像テキスト: `📍 アクセス・持ち物`
  - アクションタイプ: `テキスト`
  - 送信テキスト: `持ち物`
- **【右下ボタン】**:
  - 画像テキスト: `💬 お問い合わせ`
  - アクションタイプ: `テキスト`
  - 送信テキスト: `質問したいことがあります`
